## 1.2 Fundamental Security Concepts

### CIA Triad

The CIA Triad represents three core objectives of information security:

* **Confidentiality** — ensures that only authorised subjects can access information and resources.
* **Integrity** — ensures that data and system configurations are not modified without authorisation.
* **Availability** — ensures that authorised requests for resources are fulfilled within a reasonable amount of time.

### Non-Repudiation

Non-repudiation provides evidence that prevents an individual from denying that they performed a particular action or transaction.

**Digital signatures** can provide non-repudiation because they use asymmetric cryptography and can be publicly verified using the sender's public key.

### AAA

AAA represents three important aspects of access control:

* **Authentication** — verifies the identity of a user or service.
* **Authorization** — determines what an authenticated subject is permitted to access based on their roles or permissions.
* **Accounting** — records user activity and resource access through logs and audit trails.

Accounting contributes to **accountability**, as logged activity can be used to identify who performed an action and support investigations.

### Access Control Models

Different access control models determine how access to resources is granted:

| Model          | Key Concept                                                                             |
| -------------- | --------------------------------------------------------------------------------------- |
| **DAC**        | The owner of an object can decide who has access to it.                                 |
| **RBAC**       | Permissions are assigned to roles or groups rather than directly to individual users.   |
| **Rule-Based** | Global rules or restrictions determine whether access is allowed.                       |
| **MAC**        | Access is determined using predefined security labels assigned to subjects and objects. |
| **ABAC**       | Access decisions are based on attributes such as department, location or role.          |

### Gap Analysis

A **gap analysis** compares an organisation's current security controls and practices against a required standard or framework.

A **control gap** is the difference between the security measures that should be in place and the controls that are actually implemented.

### Zero Trust

Zero Trust is a security architecture based on the principle that **no entity should be trusted by default**.

The three core principles are:

1. **Assume breach**
2. **Verify explicitly**
3. **Use least privilege access**

Zero Trust moves away from relying solely on a network perimeter and instead focuses on verifying each access request based on factors such as identity, device health and risk.

### Policy Enforcement & Decision Points

Two important components of Zero Trust are:

* **Policy Decision Point (PDP)** — evaluates an access request and decides whether it should be allowed, denied or subjected to additional controls.
* **Policy Enforcement Point (PEP)** — enforces the decision and controls the connection between a subject and a resource.

The PDP makes the decision, while the PEP applies the decision.

### Physical Security

Physical security is an important part of an organisation's overall security posture. Physical access to facilities or equipment can allow an attacker to damage, alter or disclose information regardless of the organisation's logical security controls.

Examples of physical security controls include:

* Security guards
* CCTV
* Access badges
* Fences
* Lighting
* Access control vestibules
* Intrusion detection sensors

### Key Takeaway

Security is not achieved through a single technology or control. Effective security combines principles such as confidentiality, integrity, availability, strong access control, Zero Trust and physical security to reduce risk and protect organisational resources.
